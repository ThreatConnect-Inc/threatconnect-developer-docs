=============
Notifications
=============

Notifications allow users to track changes made to Groups, Indicators, Intelligence Requirements, Tags, Victims, and other items. Users can view notifications in the ThreatConnect user interface by clicking the **bell** icon on the top navigation bar.

The ThreatConnect v3 API allows you to retrieve notifications sent to your API user account, including notifications for job failure outcomes for feed API services.

For more information on the ``/v3/notifications`` API endpoint, see the following documentation in the ThreatConnect Developer Hub:

- `Notifications Overview <https://threatconnect.readme.io/reference/notifications-overview>`_
- `Notification Schemas <https://threatconnect.readme.io/reference/notification-schemas>`_
- `Notification Snippets <https://threatconnect.readme.io/reference/notification-snippets>`_
