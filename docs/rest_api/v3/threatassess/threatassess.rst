============
ThreatAssess
============

In ThreatConnect, under **Settings** > **Account Settings** > **ThreatAssess**, the **Recalculate ThreatAssess** feature allows you to perform targeted and prioritized recalculations of Indicator ThreatAssess scores and CAL™ Global Threat Scores on demand. Doing so ensures that these scores are current for a subset of Indicators defined by a ThreatConnect Query Language (TQL) query instead of reinitializing all Indicators or recalculating scores one Indicator at a time.

The ThreatConnect v3 API allows you to preview and execute TQL-based ThreatAssess recalculations and retrieve ThreatAssess recalculation queue counts.

For more information on the ``/v3/threatAssess`` API endpoints, see `ThreatAssess <https://threatconnect.readme.io/reference/threatassess-overview>`_ in the ThreatConnect Developer Hub.
